Edit Distance in Language Processing and Document Evaluation

Explore applications of edit distance in language processing, including Unicode normalization and text transformation, transliteration, phonetic comparison, OCR, automatic speech recognition, and machine translation evaluation. These applications use different sequence representations and processing policies, so the meaning of Levenshtein distance depends on the text representation being compared.

  1. 01

    Text Normalization and Transliteration: Unicode, Edit Distance, and Reliable Matching

    A technical guide to Unicode normalization, case folding, grapheme segmentation, transliteration, styled Unicode transformations, and their effects on Levenshtein distance and multilingual matching.

    Article·16 min read

  2. 02

    Styled Unicode Text: Characters, Symbols & String Transformation | Levenshtein.net

    Learn how styled Unicode text uses mathematical alphabets, symbols and character substitutions, how it differs from fonts, and how transformed strings relate to Levenshtein distance.

    Article·10 min read

  3. 03

    Unicode Text Transformations & Edit Distance | Levenshtein.net

    Learn how Unicode normalization, transliteration, grapheme segmentation and styled text transformations change string representation, and how Levenshtein distance compares the results.

    Article·10 min read

  4. 04

    Translation Edit Rate (TER) and Machine Translation Evaluation: Alignment, Shifts, HTER, Metrics, and Limitations

    A rigorous guide to Translation Edit Rate for machine translation, covering TER mathematics, block shifts, TERCOM alignment, HTER, multiple references, preprocessing, post-editing effort, modern MT metrics, statistical testing, and limitations.

    Article·25 min read

  5. 05

    Phonetic, Dialect, and Language Distance: Levenshtein Methods, Dialectometry, and Linguistic Similarity

    A rigorous guide to phonetic, dialect, and language distance, covering phonetic alignment, weighted Levenshtein distance, dialectometry, LDN and LDND, sound correspondences, cognates, perceptual validation, and limits of linguistic distance measures.

    Article·39 min read

  6. 06

    OCR Evaluation and Post-Correction: Character Error Rate, Ground Truth, Error Models, and Reliable Correction

    A rigorous guide to OCR evaluation and post-correction, covering CER, WER, edit-distance alignment, ground truth, Unicode, layout errors, noisy-channel models, neural correction, LLMs, over-correction, and reproducible evaluation.

    Article·39 min read

  7. 07

    Word Error Rate (WER) and ASR Evaluation: Mathematics, Alignment, Protocols, and Limitations

    A rigorous guide to word error rate in automatic speech recognition, including edit-distance alignment, scoring protocols, aggregation, multilingual issues, statistical testing, and WER limitations.

    Article·28 min read
