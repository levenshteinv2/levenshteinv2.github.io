Algorithms

Algorithms for Levenshtein Distance

This section covers the principal algorithms for computing and exploiting Levenshtein distance, including classical dynamic programming, distance-sensitive methods, bit-parallel techniques, finite-state automata, advanced exact algorithms, and indexing strategies for approximate matching.

  1. 01

    Indexing and Filtering for Edit Distance: Exact Similarity Search at Scale

    Learn exact edit-distance search at scale using length bounds, q-grams, partitioning, tries, Levenshtein automata, metric indexes, and exact verification.

    Article·18 min read

  2. 02

    Landau–Vishkin Algorithm: Bounded Edit Distance & Approximate Matching

    A rigorous guide to the Landau–Vishkin algorithm: farthest-reaching edit paths, diagonals, LCE queries, bounded edit distance, approximate matching, complexity, correctness, and implementation.

    Article·38 min read

  3. 03

    Masek–Paterson Algorithm: Four Russians Edit Distance

    A rigorous guide to the Masek–Paterson algorithm for edit distance: Four Russians blocking, boundary step vectors, precomputation, discrete costs, complexity, LCS, reconstruction, and limitations.

    Article·38 min read

  4. 04

    Levenshtein Automata: Finite-State Fuzzy String Matching

    A rigorous guide to Levenshtein automata: NFA and DFA construction, edit transitions, characteristic vectors, Schulz–Mihov automata, trie intersection, complexity, and implementation.

    Article·41 min read

  5. 05

    Myers Bit-Vector Algorithm: Bit-Parallel Edit Distance

    A rigorous guide to Myers' bit-vector algorithm for approximate string matching: relocatable dynamic programming, Pv/Mv encoding, Peq masks, carry propagation, complexity, global adaptation, and implementation.

    Article·39 min read

  6. 06

    Ukkonen Algorithm: Banded, Output-Sensitive Edit Distance

    A rigorous guide to Ukkonen's edit-distance algorithm: diagonal bands, thresholds, output-sensitive complexity, correctness, memory reduction, weighted costs, and implementation.

    Article·28 min read

  7. 07

    Wagner–Fischer Algorithm: Dynamic Programming for Edit Distance

    A rigorous guide to the Wagner–Fischer algorithm for edit distance, including recurrence, correctness proof, matrix construction, backtracking, weighted costs, complexity, memory optimization, and implementation.

    Article·29 min read
