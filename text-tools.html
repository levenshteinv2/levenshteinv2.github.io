Text transformation and string comparison

Text transformation changes a sequence, for example by substituting characters or applying normalization. String comparison measures relationships between sequences. The tools in this directory generate or transform text; they are not Levenshtein distance calculators.

Learn the underlying concepts

  • Unicode Text Transformations — how normalization and other transformations affect text representation.
  • Styled Unicode Text — the difference between character substitutions and fonts.
  • Edit Operations — insertion, deletion and substitution.
  • String Metrics — methods for comparing sequences.
