Unicode Text Tools

Unicode Text Tools provides localized generators for styled characters, symbols and decorative text. Choose a language or market below, enter text in the selected generator, and copy the result into a destination that supports those characters. These are Unicode character transformations, not font installations or edit-distance calculations.

Appearance and accessibility can vary by device and application. Avoid using decorative characters in essential information where search, screen readers or exact text matching matter.

For the technical background, see Unicode Text Transformations and Styled Unicode Text. Return to Text Tools for the broader directory.
