Unicode Text Tools

Unicode Text Tools

Unicode Text Tools is a collection of practical utilities for transforming ordinary text into alternative Unicode representations, including styled characters, symbols, decorative forms, and other copyable text variations.

These tools are practical applications of the Unicode transformation concepts documented on Levenshtein.net. The transformation changes or maps the Unicode sequence, while Levenshtein distance can be used separately to compare defined source and result sequences.

For the technical background, see Unicode Text Transformations and Styled Unicode Text .
