Ukkonen 1985: Algorithms for Approximate String Matching, Banded DP, and Distance-Sensitive Edit Distance

Esko Ukkonen's 1985 paper Algorithms for Approximate String Matching is one of the foundational papers in the algorithmic development of edit distance.

The result is frequently reduced to a familiar engineering rule:

If the maximum edit distance is k,
compute only a narrow diagonal band
of the dynamic-programming matrix.

That description captures an important consequence of the paper, but not its full contribution.

Ukkonen starts from the complete Wagner–Fischer edit-distance matrix and analyzes its dependency graph. He proves that if an optimal transformation has small cost, only a correspondingly narrow set of diagonals can belong to a minimum-cost path. From this observation he develops threshold-decision algorithms, an exact distance algorithm whose running time depends on the distance actually obtained, a more compact frontier representation for unit-cost edit distance, algorithms for recovering an optimal edit sequence, an application to longest common subsequence, and a general theory for extending the method to richer edit-operation systems—including adjacent transpositions under appropriate conditions.

The paper's principal result can be summarized as follows. For strings of lengths:

m
and
n,

with edit distance:

s,

Ukkonen obtains algorithms whose running time is:

O(
 s · min(m,n)
).

For a known threshold:

t,

he obtains a decision procedure testing:

D(A,B) <= t?

in:

O(
 t · min(m,n)
)

time and:

O(
 min(t,m,n)
)

space.

Under the special case in which every insertion, deletion, and change has unit cost, he gives a second formulation that represents each diagonal by its furthest-reaching position at each error level. This avoids storing the ordinary dynamic-programming values directly and anticipates the distance-frontier viewpoint that became central in later difference and sequence-alignment algorithms.

The most important conceptual transition is therefore:

Wagner–Fischer:

compute the entire m × n state space

        |
        v

Ukkonen:

compute only the region
that can participate
in a sufficiently cheap path

and let the amount of work
depend on the edit distance.

This is not an approximation algorithm for edit distance.

The algorithms compute or decide the exact edit distance under their stated cost models.

The word approximate in the title refers to approximate matching: strings are allowed to differ by edits. It does not mean that Ukkonen returns an approximate numerical estimate of the true edit distance.

This distinction remains essential today. See Approximate String Matching and Approximate Edit-Distance Algorithms for the two different meanings.

    m = length(A)
    n = length(B)

    if abs(m-n) > k:
        return >k

    previous = banded initial row

    for i = 1..m:

        lo = max(0, i-k)
        hi = min(n, i+k)

        current outside [lo,hi] = infinity

        for j = lo..hi:

            current[j] =

                    current[j-1] + 1,
                    previous[j-1]
                      + (A[i] != B[j])

        if all current band values > k:
            return >k

        swap(previous,current)

    return previous[n]

617. Final historical synthesis

Algorithms for Approximate String Matching represents a decisive change in how exact edit distance can be computed.

Levenshtein's 1965/1966 work supplied the insertion-deletion-substitution sequence geometry. Wagner and Fischer later gave the canonical dynamic-programming formulation, turning arbitrary string correction into a table over prefix pairs. Masek and Paterson showed that repeated blocks of that table could be precomputed to obtain a logarithmic-factor speedup.

Ukkonen attacked a different source of inefficiency.

His central observation was that when two strings are similar, the optimum transformation uses only a small edit budget. A path through the dynamic-programming matrix cannot move arbitrarily far across diagonals without paying for insertions or deletions. If the minimum cost of any length-changing operation is:

Δ > 0,

then moving across:

q

diagonals costs at least:

qΔ.

This turns a score threshold into a geometric constraint.

If the final edit distance is at most:

t,

only a narrow corridor of the prefix matrix can contain a qualifying minimum-cost dependency path.

The result is an exact threshold algorithm:

D(A,B) <= t?

)

)

The exact distance need not be known in advance. Ukkonen starts with a lower-scale threshold and doubles it until the predicate succeeds. Because the tested values form a geometric series, all failed tests together cost only a constant factor of the successful scale. This yields:

O(

)

The final part of the paper pushes the theory farther.

Instead of restricting editing operations to one-symbol insertions, deletions, and substitutions, Ukkonen considers finite sets of general substring rewrite operations:

x -> y.

This exposes a fundamental boundary of dynamic programming.

For arbitrary rewrite systems, later edits may operate on material created by earlier edits, and the transformations may no longer possess the nonchaining, order-preserving structure required by a two-dimensional prefix recurrence. Ukkonen therefore defines a restricted edit distance in which operations progress through an active portion of the string.

The generalized prefix recurrence computes this restricted distance exactly.

Using a generalized minimum cost per unit of length displacement, Ukkonen then carries the same diagonal-band reasoning into this richer model and obtains analogous threshold and distance-sensitive complexity bounds.

Finally, he examines adjacent transposition:

ab -> ba.

Under a sufficient condition on edit costs, unrestricted transformations using insertions, deletions, substitutions, and adjacent transpositions can be normalized into restricted transformations of no greater cost. The band/frontier framework can therefore be extended to this important typing-error operation.
