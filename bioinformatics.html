Edit Distance in Bioinformatics and Sequence Analysis

Edit distance provides a foundational model for comparing biological and synthetic sequences through insertions, deletions, and substitutions, but biological sequence analysis often requires richer assumptions than ordinary unit-cost Levenshtein distance can express. This section examines where edit distance fits in bioinformatics, how it relates to sequence alignment and gap models, why bounded edit distance is important in genomic search and read mapping, and how insertion, deletion, and substitution errors arise in emerging systems such as DNA data storage. The emphasis is on distinguishing generic sequence-edit similarity from biologically meaningful scoring, alignment, and inference.

  1. 01

    Edit Distance in DNA Storage: Indel Channels, Synchronization Codes, Reconstruction, and Error Correction

    A rigorous guide to edit distance in DNA storage, including indels, synchronization errors, VT codes, HEDGES, consensus, strand dropout, and robust decoding.

    Article·46 min read

  2. 02

    Edit Distance in Genomic Search and Read Mapping: Seeds, Indexes, Alignment, and Mapping Quality

    A rigorous guide to edit distance in genomic search and read mapping, covering FM-indexes, seeds, minimizers, chaining, bounded alignment, BWA, Bowtie 2, minimap2, CIGAR, NM, MAPQ, repeats, paired-end reads, and mapping uncertainty.

    Article·45 min read

  3. 03

    Sequence Alignment and Gap Models: Global, Local, Affine, and Biological Alignment Theory

    A rigorous guide to biological sequence alignment and gap models, covering Needleman-Wunsch, Smith-Waterman, semi-global alignment, linear and affine gaps, Gotoh, pair-HMMs, traceback, alignment ambiguity, and modern exact algorithms.

    Article·37 min read

  4. 04

    Edit Distance in Bioinformatics: Sequence Alignment, Biological Models, Algorithms, and Limits

    A rigorous guide to edit distance in bioinformatics, covering DNA and protein alignment, indels, gap models, sequence similarity, read mapping, biological scoring, fast algorithms, and the limits of Levenshtein distance.

    Article·38 min read
