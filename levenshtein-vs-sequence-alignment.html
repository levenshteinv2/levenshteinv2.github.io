Levenshtein Distance vs Sequence Alignment

Levenshtein distance and biological sequence alignment are often presented as separate ideas: one belongs to string algorithms, the other to bioinformatics. Mathematically, however, they are closely related.

A global alignment can represent exactly the same three primitive relationships used by classic Levenshtein distance:

symbol aligned with symbol
    ->
match or substitution

symbol aligned with gap
    ->
deletion

gap aligned with symbol
    ->
insertion.

If every mismatch costs one, every gap symbol costs one, every exact match costs zero, both sequences must be aligned from end to end, and all terminal gaps are charged normally, minimum-cost global alignment is precisely the Levenshtein problem.

But biological sequence alignment is much broader than that special case.

It can assign different scores to different substitutions, distinguish opening a gap from extending an existing one, reward conserved amino-acid replacements, find only the best local region rather than align complete sequences, leave selected terminal gaps unpenalized, and evaluate biological resemblance under an explicit scoring model.

The central relationship is therefore:

Levenshtein distance
is closely related to
global sequence alignment

but

sequence alignment
is not synonymous with
Levenshtein distance.

The distinction becomes especially important in bioinformatics because:

minimum edit count
!=
biological similarity

alignment score
!=
edit distance

gap
!=
known historical insertion/deletion

high similarity
!=
proof of homology

optimal alignment
!=
unique alignment

optimal alignment
!=
true evolutionary history.

This article develops those boundaries rigorously. It derives Levenshtein as a special global-alignment cost model, explains the historical relationship among Needleman-Wunsch, Sellers, Smith-Waterman, and Gotoh, compares global, local, and semi-global alignment, develops linear and affine gap penalties, explains nucleotide and protein substitution matrices, and examines when ordinary edit distance is the appropriate biological model—and when it is not.

1. What is a sequence alignment?

Let:

X = x1 x2 ... xm

Y = y1 y2 ... yn.

An alignment inserts gap symbols into the two sequences so that both expanded sequences have the same length.

2. Example

X:
A C G T

Y:
A - G T.

The columns are:

A / A
C / -
G / G
T / T.

3. Alignment columns

For ordinary pairwise alignment, useful column types are:

Column Interpretation
x / x Match
x / y Mismatch/substitution
x / - Gap in second sequence
- / y Gap in first sequence

4. Gap-gap columns carry no useful information

- / -

can simply be removed without changing the correspondence between sequence symbols.

Ordinary optimal pairwise alignment therefore excludes such columns.

5. Alignment is a hypothesis about correspondence

When an alignment contains:

A C G T
A - G T,

it proposes that:

A corresponds to A

C corresponds to a gap

G corresponds to G

T corresponds to T.

6. An alignment is not merely a score

The alignment itself provides a structured explanation.

The score summarizes that explanation under a chosen scoring system.

7. Levenshtein distance can also be written as alignment optimization

Assign alignment-column costs:

cost(x,x) = 0

cost(x,y) = 1
for x != y

cost(x,-) = 1

cost(-,y) = 1.

8. Alignment cost

For alignment A:

Cost(A)
=
sum of its column costs.

9. Levenshtein as minimum-cost global alignment

dL(X,Y)
=
min_A Cost(A)

where the minimum ranges over complete end-to-end alignments of X and Y.

10. This equivalence is exact under this cost model

Each mismatch corresponds to a substitution.

Each:

x / -

column corresponds to a deletion.

Each:

- / y

column corresponds to an insertion.

11. Every Levenshtein edit script creates an alignment

For example:

ACGT
->
AGT

using deletion of C corresponds to:

A C G T
A - G T.

12. Every valid alignment creates an edit script

Read alignment columns from left to right and interpret mismatches and gaps as edit operations.

This establishes the structural equivalence.

13. Dynamic-programming recurrence

Minimum-cost global alignment with these costs obeys:

D(i,j)
=
min(
    D(i-1,j) + 1,
    D(i,j-1) + 1,
    D(i-1,j-1) + [xi != yj]
).

14. These are the familiar Levenshtein branches

D(i-1,j) + 1
=
delete xi

D(i,j-1) + 1
=
insert yj

D(i-1,j-1) + mismatch
=
match/substitute.

15. Therefore Levenshtein is already an alignment algorithm

More precisely:

classic Levenshtein
=
minimum-cost global alignment
under one specific
linear unit-cost scoring model.

16. Why then distinguish edit distance and sequence alignment?

Because sequence alignment permits much richer definitions of:

  • what a residue match is worth;
  • what a mismatch costs or rewards;
  • how gaps are penalized;
  • which parts of the sequences must align;
  • which boundaries are free;
  • how the resulting score is interpreted.

17. Alignment is a framework, not one metric

“Sequence alignment” can mean many optimization problems.

18. Common alignment objectives

global alignment

local alignment

semi-global alignment

overlap alignment

query-global / target-local alignment

affine-gap alignment

profile alignment

graph alignment.

19. Levenshtein fixes many of these choices implicitly

Classic Levenshtein normally means:

global

unit substitution cost

unit insertion cost

unit deletion cost

linear gap cost

all terminal edits charged.

20. Sequence alignment makes those choices explicit

That is one reason biological alignment should not be reduced to the phrase:

"Levenshtein for DNA."

21. Historical perspective: Levenshtein

Vladimir Levenshtein's 1965 work studied binary codes capable of correcting deletions, insertions, and binary-symbol substitutions.

See the MathNet bibliographic record.

22. Historical terminology warning

The English title is commonly translated as:

Binary Codes Capable of Correcting
Deletions, Insertions and Reversals.

In this historical binary-code context, “reversal” refers to reversal/change of the binary symbol value—not the adjacent-character transposition primitive of Damerau-Levenshtein distance.

23. Coding and biological alignment arose from related sequence problems

Both fields needed methods for reasoning about:

  • substitutions;
  • insertions;
  • deletions;
  • correspondence after synchronization changes.

24. Needleman-Wunsch

Saul Needleman and Christian Wunsch published their foundational method for comparing amino-acid sequences in 1970.

See A general method applicable to the search for similarities in the amino acid sequence of two proteins.

25. Needleman-Wunsch is fundamentally a global alignment method

The aim is to compare the sequences across their full extents under a defined similarity-scoring system.

26. Global alignment

A global alignment consumes:

all symbols of X

and

all symbols of Y.

Nothing is discarded merely because it aligns poorly.

27. Sellers' distance formulation

Peter Sellers developed a minimum-distance formulation for finite sequences.

See An algorithm for the distance between two finite sequences.

28. Similarity maximization and distance minimization can describe the same optimization

This is a crucial conceptual bridge.

One formulation can ask:

maximize alignment similarity.

Another can ask:

minimize alignment dissimilarity.

29. Smith, Waterman, and Fitch compared these frameworks directly

Their 1981 paper showed conditions under which the Needleman-Wunsch similarity formulation and Sellers-style distance formulation produce equivalent optimal alignments.

See Comparative biosequence metrics.

30. Therefore “score” versus “distance” is not always a fundamental algorithmic divide

Sometimes the two objectives are related by a transformation of the scoring system.

31. But arbitrary biological scores cannot automatically be treated as edit metrics

A biological substitution matrix can assign:

  • different scores to different matches;
  • different scores to different mismatches;
  • positive scores to some nonidentical residue pairs.

That generally does not correspond to ordinary unit edit distance.

32. Modern textbook global alignment recurrence

With substitution score:

s(xi,yj)

and linear gap penalty:

g > 0,

a common score-maximizing recurrence is:

F(i,j)
=
max(
 F(i-1,j-1) + s(xi,yj),
 F(i-1,j)   - g,
 F(i,j-1)   - g
).

33. Initialization for full global alignment

F(0,0) = 0

F(i,0) = -i g

F(0,j) = -j g.

34. Terminal gaps therefore cost normally

The algorithm is forced to account for the entire lengths of both sequences.

35. Converting that recurrence into Levenshtein

Choose:

s(x,x) = 0

s(x,y) = -1
for x != y

g = 1.

Then maximizing the score is equivalent to minimizing the number of unit edits.

36. Relationship

max_score(X,Y)
=
-dL(X,Y)

under this specific global scoring system.

37. This is a special case, not the definition of biological alignment

Changing the scoring system changes the meaning of the optimum.

38. Worked unit-cost example

X:
A C G T

Y:
A G T.

Optimal alignment:

A C G T
A - G T.

Unit edit cost:

1.

Therefore:

dL(X,Y)=1.

39. Biological scoring can assign another value to exactly the same alignment

Suppose:

match = +2

mismatch = -1

gap symbol = -2.

The alignment has:

3 matches
1 gap.

Therefore score:

3(2) - 2
=
4.

40. The alignment stayed the same

Its numerical interpretation changed.

41. Alignment and score must therefore be separated conceptually

alignment
=
correspondence structure

score
=
evaluation of that structure
under one scoring model.

42. Different scores can select different optimal alignments

The scoring system does more than label an alignment after it has been found.

It determines which alignment is optimal.

43. Example principle

A scoring system with cheap gaps may prefer:

more gaps
+
fewer mismatches.

A scoring system with expensive gaps may prefer:

fewer gaps
+
more mismatches.

44. This tradeoff does not exist in the same form under fixed unit Levenshtein costs

There:

one mismatch = 1

one gap symbol = 1.

45. Biological sequence alignment usually does not treat every substitution equally

This is particularly important for proteins.

46. Twenty amino acids are not twenty mutually equidistant symbols biologically

Different residues vary in:

  • physicochemical properties;
  • evolutionary substitution frequencies;
  • structural constraints;
  • background abundance.

47. Classic Levenshtein ignores all such distinctions

For any two unequal symbols:

cost = 1.

48. Protein sequence alignment can use substitution matrices

A matrix:

S(a,b)

assigns a score to aligning amino acid a with amino acid b.

49. BLOSUM

Steven and Jorja Henikoff introduced BLOSUM matrices derived from conserved protein blocks.

See Amino acid substitution matrices from protein blocks.

50. BLOSUM scores are nonuniform

Under BLOSUM62, different residue correspondences receive very different values.

For example, the matrix assigns a high score to certain strongly conserved matches and substantial negative scores to unlikely substitutions.

51. BLOSUM62 example

A reviewed description of BLOSUM62 reports:

W : W = 11

D : L = -4.

That alone demonstrates a structure fundamentally different from:

match = 0

every mismatch = 1.

52. Some nonidentical amino-acid pairs can receive positive substitution scores

In biological scoring, a nonidentical replacement can be considered more compatible than expected by chance.

53. Therefore substitution is not synonymous with biological mismatch penalty

Under Levenshtein:

A != B
->
cost 1.

Under a protein scoring matrix:

score(A,B)

depends on the residue pair.

54. BLOSUM scoring has a log-odds interpretation

Broadly, positive values indicate residue correspondences occurring more often in related sequence blocks than expected under the background model, while negative values indicate less favorable correspondence.

55. The score therefore incorporates population evidence

Classic Levenshtein is corpus-independent.

BLOSUM is derived from empirical biological sequence relationships.

56. PAM

The PAM family provides another classical protein substitution framework based on estimated amino-acid replacement processes.

57. PAM and BLOSUM are not interchangeable tables

They were derived using different methodologies and numerical scales.

58. Matrix choice changes alignment behavior

It can alter:

  • which substitutions are favored;
  • which alignment becomes optimal;
  • database-search sensitivity;
  • the meaning of a raw score.

59. Gap penalties must be considered jointly with substitution scoring

A matrix cannot be evaluated independently from the price assigned to creating and extending gaps.

60. Nucleotide alignment can use simpler scoring

For DNA, an elementary model may use:

match reward

mismatch penalty

gap penalty.

61. But nucleotide substitutions can also be nonuniform

Applications can distinguish:

  • transitions;
  • transversions;
  • base-quality evidence;
  • context-dependent error models.

62. Ordinary Levenshtein remains valuable as a deliberately simple nucleotide model

For some read-mapping or approximate-search problems, the desired criterion is literally:

number of substitutions
+
insertions
+
deletions.

In that case edit distance is not an inferior approximation—it is the intended objective.

If the application asks:

of this reference substring?

unit edit distance can be exactly right.

64. The right question is model fit

Do the scores represent
the transformations
that matter in this task?

65. Global alignment

Global alignment is best suited when the goal is to compare both sequences across their complete extents.

66. Typical interpretation

sequence X
from beginning to end

aligned against

sequence Y
from beginning to end.

67. Global does not mean “no gaps”

Internal and terminal gaps can occur.

It means all sequence symbols participate in the alignment.

68. Full-string Levenshtein is inherently global

Classic:

69. This creates a natural correspondence

Levenshtein
<->

70. But global biological alignment can have arbitrary substitution and gap scores

Therefore:

global alignment
does not imply
Levenshtein distance.

71. Local alignment asks a different question

Instead of:

How well do the full sequences correspond?

it asks:

Which pair of subsequences
has the strongest alignment?

72. Smith-Waterman

Temple Smith and Michael Waterman introduced the classic local-alignment algorithm in 1981.

See Identification of common molecular subsequences.

73. Basic local recurrence

For linear gap penalty:

  H(i-1,j-1)+s(xi,yj),

74. The zero term is fundamental

If an alignment prefix becomes unfavorable:

restart from zero.

75. Therefore local alignment can ignore poor flanking regions

The traceback begins at the highest-scoring cell and ends when a zero-score boundary is reached.

X:

ACGT
ACGT.

78. Local alignment can focus entirely on ACGT

If matches are positively rewarded, the central:

79. This is not an edit distance between complete strings

The poor flanks can contribute nothing.

80. Therefore local alignment violates the intuition of metric identity

Two very different full sequences can have a strong or even perfect local segment.

81. A local-alignment score should not automatically be converted into a metric distance

For example:

distance = C - local_score

has no guaranteed metric meaning merely because it decreases as similarity increases.

82. Local alignment is designed for motif/domain-like relationships

Examples include:

  • shared protein domains;
  • conserved sequence regions;
  • short homologous segments;
  • query-to-database local similarity.

83. Local alignment and approximate substring matching are conceptually related

Both allow the important correspondence to occur inside a larger target.

84. But they need not use the same objective

Approximate string matching often asks:

find target substrings
within <= k edits.

Smith-Waterman asks:

maximize a local alignment score.

85. Similar search region, different mathematical criterion

This distinction is important for terminology.

86. Semi-global alignment lies between global and local

Semi-global alignment typically aligns one or both sequences substantially end-to-end while making selected terminal gaps free.

Target:

TTACGTAA.

88. Full-string Levenshtein distance

Four additional target characters must be inserted:

--ACGT--
TTACGTAA

0.

90. This can model exact substring search

Allowing internal edits then creates approximate query-to-substring alignment.

91. Semi-global alignment has several variants

One may make free:

  • both ends of sequence X;
  • both ends of sequence Y;
  • only leading gaps;
  • only trailing gaps;
  • selected combinations.

92. Therefore “semi-global” is not one unique boundary condition

Always specify which terminal gaps are unpenalized.

93. Overlap alignment

Another common objective emphasizes an overlap between a suffix of one sequence and a prefix of another.

Again the internal recurrence can resemble global dynamic programming while boundary initialization changes the objective.

Different applications require different endpoints.

98. Gap models create another major difference

Classic Levenshtein assigns one cost for every inserted or deleted symbol.

=

100. This is a linear gap cost

Every additional gap symbol contributes the same increment.

101. Biological sequence alignment often distinguishes gap opening and extension

The motivation is that a contiguous stretch of missing residues can represent one longer indel episode more naturally than many independent gap events.

A common convention is:

=

107. Why affine gaps differ from Levenshtein

Suppose four consecutive residues are absent.

Levenshtein assigns:

4 deletion operations.

108. Affine model views one gap run differently

With:

g_extend = 1

=

+

under the same simplified opening interpretation.

110. Therefore gap clustering matters

The scoring system prefers:

one long gap

over:

several separate gap openings

when extension is cheaper than opening.

111. Linear Levenshtein does not distinguish these cases

Four deleted symbols cost four regardless of whether they form one contiguous run or several isolated deletions.

112. Affine gap scoring requires additional dynamic-programming state

To know the next gap cost, the algorithm must know whether it is:

opening a gap

or:

extending an existing gap.

113. Gotoh's algorithm

Osamu Gotoh showed how affine-gap sequence alignment can be computed efficiently using coupled dynamic-programming states.

118. The state remembers whether the current alignment is already inside a gap

This is precisely what one-matrix linear-gap Levenshtein does not need to remember.

119. Affine-gap global alignment remains quadratic-time in the standard pairwise formulation

O(mn)

time, with a constant factor reflecting the multiple states.

120. It is not “Levenshtein plus a different number”

The dynamic-programming state space changes.

121. Local alignment can also use affine gaps

Smith-Waterman-style zero resetting can be combined with Gotoh-style match and gap states.

122. Semi-global alignment can also use affine gaps

Gap model and boundary model are independent design dimensions.

123. Alignment design therefore has several axes

BOUNDARY MODEL:

124. Sequence alignment is a family of optimization problems

There is no single “sequence alignment distance.”

125. Gap penalties are models, not biological observations

An alignment algorithm inserts a gap because doing so improves the objective under its scoring model.

126. The gap does not prove a historical deletion occurred

Without ancestral information, the same observed difference may be interpreted as:

deletion on one lineage

or

insertion on the other lineage.

127. Gap direction is usually not recoverable from two descendants alone

This requires evolutionary context beyond pairwise alignment.

128. Alignment gap is not identical to physical mutation event

Several historical events can generate the same present-day alignment pattern.

129. Conversely, one historical event can produce several alignment columns

A multi-residue insertion creates a run of gap columns.

130. Therefore

alignment gap
!=
known evolutionary indel event.

131. The same principle applies to mismatches

An aligned residue pair:

A / G

does not by itself tell which ancestral residue changed.

132. Alignment is endpoint optimization, not direct historical reconstruction

This mirrors the broader edit-distance distinction:

minimum edit script
!=
actual physical edit history.

133. Multiple optimal alignments can exist

Consider:

X:
AAAA

Y:
AAA.

134. Any one of several A positions can be aligned to a gap

All such alignments have the same unit edit cost:

1.

135. The distance is unique

The alignment need not be.

136. Therefore

optimal score
!=
unique alignment.

137. Tie-breaking is an implementation choice

Two libraries can return:

same optimal score

but:

different optimal alignments.

138. This matters when interpreting positions

A downstream system should not treat one arbitrary traceback as definitive biological evidence.

139. Near-optimal alignments can also be biologically plausible

A tiny score difference can separate several competing correspondence hypotheses.

140. Scalar optimum hides uncertainty

Reporting only:

score = 87

does not communicate whether:

  • the best alignment is unique;
  • many alternatives score 86;
  • gap placement is unstable.

141. Alignment uncertainty is separate from algorithmic exactness

Dynamic programming may compute the optimum exactly.

The biological interpretation can still be uncertain.

142. Exact optimization does not mean biological truth

exact DP
=
exact optimum
under chosen scoring model

not

exact reconstruction
of evolution.

143. Scoring models encode assumptions

The optimum changes if one changes:

  • substitution matrix;
  • gap opening cost;
  • gap extension cost;
  • terminal-gap policy;
  • alignment mode.

144. Therefore there is no score independent of model choice

An “optimal alignment” should always be understood as:

optimal under specified scoring parameters.

145. Percent identity is another different quantity

After producing an alignment, one may count:

number of aligned identical residue pairs.

146. Percent identity requires a denominator

Possible conventions include:

  • alignment length including gaps;
  • number of aligned residue-residue columns;
  • shorter sequence length;
  • another explicitly defined denominator.

147. Therefore “80% identity” should be defined operationally

Different software can use different denominator conventions.

148. Identity is not alignment score

Two alignments can have equal percent identity but different:

  • substitution-matrix scores;
  • gap structures;
  • gap penalties.

149. Similarity is also not identity

Protein alignments sometimes call nonidentical but favorably scoring residue substitutions:

similar.

150. Therefore

identity
!=
similarity.

151. Biological homology is stronger still

Homology refers to evolutionary common ancestry.

It is not simply a numerical synonym for sequence similarity.

152. High sequence similarity can support a homology hypothesis

But the alignment score itself does not logically define common ancestry.

153. Low edit distance is therefore not equivalent to homology

low dL
!=
proven homology.

154. High edit distance does not automatically disprove evolutionary relationship

Sequences can diverge extensively over long evolutionary periods.

155. Smith, Waterman, and Fitch explicitly distinguished similarity-style sequence comparison from evolutionary interpretation

Their comparative work is useful precisely because mathematically related scoring systems need not imply the same biological conclusion.

156. “Percent homology” should generally be avoided

Homology is a relationship.

Percent identity or percent similarity are quantitative sequence properties.

157. Edit distance is even farther removed from biological ancestry

It describes sequence endpoints under an operation model.

158. Biological scoring can incorporate empirical substitution likelihood

This is one reason protein alignment can detect relationships obscured by raw mismatch counting.

159. Same edit count can conceal different biological evidence

Any nonidentical one-residue pair has:

Levenshtein distance = 1.

160. Biological substitution matrices distinguish those pairs

A conservative amino-acid replacement can score much better than an improbable replacement.

161. Thus Levenshtein collapses a rich substitution matrix into

same
vs
different.

162. This can be desirable for computational simplicity

But it discards biological information.

163. Conversely, substitution matrices can be inappropriate outside their domain

BLOSUM62 should not be used to compare:

  • ordinary English words;
  • package names;
  • user identifiers;
  • log-event labels

merely because it is “more sophisticated.”

164. Domain specificity matters

A richer scoring model is only better when its assumptions match the data-generating process.

165. Sequence alignment scores can be positive or negative

Edit distance is ordinarily nonnegative.

166. Therefore raw biological alignment score is not a metric distance

A score of:

120

does not have the same mathematical interpretation as:

167. Score magnitudes depend on scoring scale

If all substitution and gap values are multiplied by two:

optimal alignment
may stay unchanged

while:

168. Raw alignment scores are therefore model-dependent units

Comparing raw scores generated under different substitution matrices or gap parameters can be misleading.

169. Statistical significance is another layer

Sequence-search systems can ask whether an observed high score is unusually large under a background sequence model.

170. Karlin-Altschul statistics

Karlin and Altschul developed foundational statistical theory for high-scoring molecular-sequence segments.

See Methods for assessing the statistical significance of molecular sequence features by using general scoring schemes.

171. Statistical significance is not edit distance

An E-value or significance measure incorporates:

  • score;
  • search-space size;
  • scoring system;
  • background assumptions.

172. A raw Levenshtein distance has none of those statistics automatically

For:

  • alphabet;
  • length;
  • corpus;
  • sequence distribution.

173. Distance and significance are different questions

distance:
How many modeled edits apart?

How surprising is the observed similarity?

174. BLAST introduces another distinction

BLAST is a heuristic database-search method designed to find high-scoring local sequence similarities efficiently.

See Basic Local Alignment Search Tool.

175. BLAST is not synonymous with Smith-Waterman

Smith-Waterman dynamic programming computes an exact optimum for its local-alignment scoring formulation.

exact optimization for one pair

178. Sequence database search requires candidate discovery

Running full quadratic dynamic programming against every database sequence can be prohibitively expensive.

179. Search systems therefore use filters, indexes, seeds, or heuristics

The same architectural principle appears in indexing and filtering for edit distance.

180. Exact verifier does not guarantee exact retrieval

If a heuristic candidate generator misses the best target:

181. Candidate recall must therefore be separated from alignment optimality

183. Candidate alignment can be exact even when the mapper is heuristic globally

An exact dynamic-programming alignment at one candidate location does not prove that every possible genomic location was examined.

184. Pairwise optimization and database optimality are different guarantees

This is often overlooked.

198. Scoring systems affect algorithmic guarantees

205. Linear gap penalties and edit distance

206. This begins to resemble generic sequence-alignment cost functions

207. Weighted edit distance can still be called alignment

208. Affine gaps break the independent-column cost assumption

Correspondence is not directly observed.

215. Terminal gap policy can be biologically meaningful

Suppose one sequence is a fragment of another.

Make unobserved terminal portions free while still penalizing internal gaps.

218. This is common in query-versus-reference problems

The correct boundary condition follows from how sequences were obtained.

Only a subset of both sequences may contain the relationship of interest.

307. Reference pseudocode: Levenshtein as global alignment

function levenshtein(X, Y):

    D[i][0] = i
    D[0][j] = j

    for i in 1..len(X):

        for j in 1..len(Y):

            mismatch =
                0 if X[i] == Y[j]
                else 1

            D[i][j] =
                min(
                    D[i-1][j] + 1,
                    D[i][j-1] + 1,
                    D[i-1][j-1]
                      + mismatch
                )

    return D[m][n]

308. Reference pseudocode: global score maximization

function global_alignment(X, Y,
                          score,
                          gap):

    F[0][0] = 0

    for i in 1..m:
        F[i][0] =
            F[i-1][0] - gap

    for j in 1..n:
        F[0][j] =
            F[0][j-1] - gap

    for i in 1..m:

        for j in 1..n:

            F[i][j] =
                max(
                  F[i-1][j-1]
                    + score(X[i],Y[j]),

                  F[i-1][j]
                    - gap,

                  F[i][j-1]
                    - gap
                )

    return F[m][n]

                         score,
                         gap):

                max(

                  H[i-1][j]
                    - gap,

                  H[i][j-1]
                    - gap

339. Final interpretation

The relationship between Levenshtein distance and sequence alignment is much closer than their usual disciplinary separation suggests.

At the mathematical core, both align ordered sequences by deciding whether symbols should correspond directly or be separated by gaps. If a complete end-to-end alignment assigns cost zero to matches and cost one to substitutions, insertions, and deletions, minimum alignment cost is exactly Levenshtein distance.

In that sense:

Levenshtein
=
a particular global alignment model.

But biological sequence alignment expands almost every assumption of that model.

The first expansion is the substitution model. Classic Levenshtein treats every unequal pair identically. Protein alignment can use matrices such as BLOSUM or PAM, where residue pairs receive different scores according to empirically or evolutionarily motivated substitution patterns. A conservative replacement and an unlikely replacement therefore need not carry the same evidence.

The second expansion is the gap model. Levenshtein assigns independent linear cost to every inserted or deleted symbol. Affine-gap alignment distinguishes the cost of opening a gap from extending it, allowing one long gap to represent a different hypothesis from several independent gaps. Gotoh's dynamic-programming formulation achieves this by maintaining separate match and gap states.

The third expansion is the alignment objective. Classic Levenshtein is global: every symbol of both strings contributes to the final distance. Needleman-Wunsch-style global alignment shares that end-to-end structure but can use richer scoring. Smith-Waterman local alignment instead searches for the strongest pair of internal subsequences. Semi-global alignment changes terminal-gap conditions so that one sequence can align to a region of another without paying for irrelevant flanks.

These relationships reveal why the familiar distinction:

edit distance
versus
sequence alignment

is too crude.

A more accurate hierarchy is:

=
general correspondence framework

Levenshtein
=
global minimum-cost alignment

=
global score optimization

Smith-Waterman
=
local score optimization

=
efficient affine-gap state model.

The historical literature also shows that distance minimization and similarity maximization need not represent fundamentally different mathematics. Sellers developed finite-sequence distance formulations, while Smith, Waterman, and Fitch later demonstrated explicit conditions under which Sellers-style distance and Needleman-Wunsch-style similarity optimization are equivalent.

The differences that matter are therefore the scoring model, gap model, representation, and boundary conditions.

For ordinary strings, unit-cost Levenshtein remains one of the cleanest possible models when insertions, deletions, and substitutions genuinely represent the relevant differences.

For biological sequence analysis, however, richer alignment models often become necessary because residue substitutions are nonuniform, contiguous gaps should not always behave like independent edits, and the biologically interesting relationship may be local rather than global.

The practical rule is therefore:

Use Levenshtein
when the target quantity
is simple edit geometry.

Use global sequence alignment
when complete sequence correspondence

Use affine gaps

Use biological substitution matrices
when different residue substitutions

The broader sequence alignment and gap models framework develops those models in detail, while edit distance in bioinformatics explains where ordinary edit distance remains useful.
