Masek–Paterson 1980: Four Russians Edit Distance, Block Precomputation, and the O(n²/log n) Algorithm

William J. Masek and Michael S. Paterson's 1980 paper A Faster Algorithm Computing String Edit Distances is a landmark in the algorithmic history of edit distance because it showed that the classical quadratic dynamic-programming table does not have to be evaluated one cell at a time.

The paper starts from the Wagner–Fischer dynamic program and asks a deceptively simple question:

If many small dynamic-programming regions
have the same local inputs,

why recompute the same internal work
every time they appear?

Masek and Paterson answer by applying the technique now commonly called the Four Russians method. The full edit-distance matrix is divided into logarithmic-size square blocks. Instead of explicitly recomputing every cell inside every block, the algorithm precomputes the possible behavior of a block and later replaces an entire block calculation by a lookup.

Under two central restrictions:

1. the alphabet is finite;

2. all edit-operation costs are
   integral multiples of one
   common positive real number,

the number of possible local block states becomes finite enough for this strategy to work.

For strings of lengths n and m, with n ≥ m, the paper obtains:

O(
 n · max(1, m/log n)
)

time.

When both strings have length proportional to n, this becomes the famous:

O(n²/log n).

The result is important for several reasons.

First, it provided an asymptotic improvement over the standard:

O(n²)

dynamic-programming bound.

Second, it showed that the regular local structure of an edit-distance matrix can be exploited algorithmically.

Third, it exposed a subtle fact that is easy to miss in simplified descriptions of Four Russians algorithms: the speedup depends not merely on dividing the table into blocks, but on proving that each block can be described by a sufficiently small finite state.

Fourth, the paper investigates its own assumptions. It does not simply state that discrete costs are convenient; it constructs a nondiscrete cost system for which the number of local step values becomes unbounded, destroying the efficient precomputation strategy.

Finally, Masek and Paterson treat more than the scalar distance. They discuss recovering an optimal edit path, space requirements, the longest common subsequence problem, and the computational model in which the logarithmic speedup is claimed.

484. Myers can be exceptionally practical for suitable pattern lengths and machine words

but is hardware-representation dependent.

485. No single algorithmic chronology equals a universal performance ranking

This is one of the broader lessons of the Edit Distance Algorithms section.

500. Final technical interpretation

A Faster Algorithm Computing String Edit Distances is not fundamentally a paper about a cleverer formula for Levenshtein distance.

The underlying recurrence is already Wagner–Fischer.

The paper's breakthrough lies in discovering that the enormous dynamic-programming state space contains a reusable finite local structure.

The starting point is the familiar matrix:

δ(i,j)
=
min(
 δ(i-1,j-1) + replacement,

 δ(i-1,j) + deletion,

 δ(i,j-1) + insertion
).

A cell-by-cell implementation performs:

Θ(nm)

local recurrence computations.

Masek and Paterson divide this matrix into logarithmic blocks.

But merely dividing the matrix does not help. If a block must still be recomputed internally every time it appears, the total work remains essentially quadratic.

The critical question is therefore:

Can the behavior of a block
be summarized by
a small finite signature?

Absolute DP boundary values cannot provide that signature because they increase without bound as one moves through the matrix.

Masek and Paterson instead represent each boundary by adjacent differences:

step_i
=
DP_i
-
DP_(i-1).

This removes arbitrary additive offsets.

Then Lemma 3 shows that these differences are bounded:

-I <= vertical step <= D

-D <= horizontal step <= I.

Boundedness alone is not enough. A bounded interval still contains infinitely many real numbers.

The second ingredient is the discreteness assumption:

every primitive edit cost
is an integer multiple
of one positive real r.

Every DP value and every adjacent difference therefore lies on the same arithmetic lattice.

A bounded lattice interval contains only finitely many points.

Hence:

bounded steps
+
discrete costs
=
finite step alphabet.

Now each block is determined by only:

its source substring,

its target substring,

its top input step vector,

its left input step vector.

For fixed finite alphabet and fixed discrete cost system, the number of such signatures grows exponentially only with the block side length:

c^t

for a constant c.

This is precisely what permits:

t = Θ(log n).

Algorithm Y enumerates the possible signatures and computes each block's outgoing step vectors in advance.

Algorithm Z then traverses the actual edit matrix at block resolution:

incoming step vectors
+
local substrings
        |
        v
table lookup
        |
        v
outgoing step vectors.

The full matrix contains approximately:

nm/t²

blocks.

Each block requires boundary-scale work of approximately:

Θ(t).

Therefore:

Θ(
 nm/t
).

Choosing:

t = Θ(log n)

gives:

O(nm/log n).

For equal-length strings:

O(n²/log n).

For a shorter string below logarithmic length, the paper's rectangular analysis reaches:

O(n).

The paper also explains that exact path reconstruction remains possible. One option regenerates only those logarithmic blocks crossed by an optimal path, yielding:

O(n log n)

traceback time in the equal-length case. Another stores much more internal information and permits linear traceback at an:

O(n²/log n)

space cost. If only the distance is required, block rows can be overwritten so the per-input working storage becomes linear.

The same framework computes longest common subsequences using:

match = 0

mismatch = 2

insert = 1

delete = 1.

Then:

LCS(A,B)
=
(
 |A|
 +
 |B|
 -
 δ(A,B)
)
/2.

But perhaps the most intellectually valuable part of the paper comes after the algorithm itself.

The authors ask whether discreteness is really necessary.

They construct a finite-alphabet weighted edit problem involving an irrational replacement cost. Carefully chosen strings force neighboring optimal diagonal paths to produce increasingly many distinct adjacent DP differences.

The local step alphabet is no longer bounded in cardinality independently of input length.

Consequently:

no fixed finite set
of block boundary states
captures every possible block.

The Four Russians precomputation used by Algorithm Y then loses its efficiency.

This does not establish that arbitrary real-valued edit distance can never be accelerated. It establishes something subtler and more useful:

the success of this algorithm
depends on the algebraic finiteness
of its compressed local state.

That is the deepest lesson of Masek–Paterson.

The Four Russians method is often taught as:

split matrix into blocks

precompute blocks

use lookup table.

The 1980 paper shows that the real reasoning is:

find local invariance

        |
        v

replace absolute state
with relative state

        |
        v

prove relative state
is bounded

        |
        v

prove bounded state
is discrete

        |
        v

obtain finite state alphabet

        |
        v

enumerate local transitions

        |
        v

choose logarithmic block size

        |
        v

replace Θ(log² n)
cell work

with Θ(log n)
boundary work

        |
        v

obtain O(n²/log n).

This is why the paper is much more than an isolated historical speedup.

It is a model example of a broad algorithm-design principle:

when a dynamic program appears
to have too many states,

look for an equivalence relation
that makes locally different
absolute states
computationally identical.

For edit distance, that equivalence relation is translation of boundary values, and the quotient representation is the vector of adjacent differences.

The later history of edit-distance algorithms moved in several different directions.

Ukkonen's 1985 paper exploits small distance rather than repeated block states. Myers later exploits machine-word bit parallelism. Modern filtering methods avoid exact verification for obviously distant candidates. Approximation algorithms relax exactness. Conditional hardness results suggest that a truly polynomial improvement over quadratic exact computation would have major complexity-theoretic consequences.

Yet the Masek–Paterson result retains a special place in that history.

It demonstrated that exact edit distance could cross below the obvious quadratic cell-count barrier without changing the distance, restricting the actual edit distance, or accepting approximation.

The saving was only logarithmic.

But conceptually it changed the question from:

Must every DP cell
be computed?

to:

How much of the DP matrix
is genuinely new information?

That question remains central to algorithm design today.

For an implementation-oriented explanation of the technique, see Masek–Paterson Algorithm. For the quadratic baseline it accelerates, see Wagner–Fischer 1974. For the next foundational paper in the algorithmic sequence, continue to Ukkonen 1985: Algorithms for Approximate String Matching.
